Il dithering

Un piccolo JPEG di rumore moltiplicato sopra l'SVG: grana "fotografica" al posto del vettoriale piatto.

.noise-overlay { position: absolute; inset: 0; background-image: var(--noise-texture); /* un piccolo JPEG di rumore */ background-size: 10% 10%; background-repeat: repeat; opacity: 0.2; mask: radial-gradient(circle, black 50%, transparent 70%); /* vignetta */ mix-blend-mode: multiply; /* moltiplica i pixel → scurisce a chiazze */ } ›
