Un colore → tutto il metallo

Da un solo colore scelto dall'utente derivi luci, ombre e riempimenti con i relative colors OKLCH, e un @supports come fallback.

:root { --fittings-color: #c0c0c0; } /* l'unico colore in input */ .thick { fill: var(--fittings-color); /* fallback */ @supports (color: oklch(from red l c h)) { fill: oklch(from var(--fittings-color) clamp(0.5, calc(l * 1.5), 2) c h); /* luce */ } } .filling { fill: oklch(from var(--fittings-color) clamp(0.55, calc(l * 0.8), 0) c h); /* ombra */ } ›
