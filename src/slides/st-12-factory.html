Una prop, una factory

Il componente ha un solo ingresso: inputs. Quindi ogni test parte da qui.

const makeBaseInputs = (overrides = {}): ShowerPreviewInputs.Encoded => ({ panelShape: "rectangular", sides: 2, width: { left: 800, right: 800 }, height: { left: 2000, right: 2000, internal: 2000 }, showerTray: { exist: true, height: 150 }, doors: { position: "left", quantity: 1, width: 500, /* … */ }, ...overrides })

Nessuno store, nessun router, nessuna API. Lo stesso disaccoppiamento che rendeva possibile il web component rende i test banali da scrivere.
